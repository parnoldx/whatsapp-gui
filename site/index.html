Installation

Install from Source

Clone the repository, install system dependencies with pacman, and build cleanly into ~/.local.

1

Build & Install

Installs whatsapp-gui and the bundled wacli CLI to ~/.local/bin:

Terminal 
git clone https://github.com/parnoldx/whatsapp-gui.git && cd whatsapp-gui
make dependencies   # once: install deps via pacman
make install
2

First Run: Pairing

The GUI has no pairing screen — pair once with the bundled wacli CLI (installed to ~/.local/bin by make install):

Terminal 
wacli auth

Scan the terminal QR code in WhatsApp on your phone: Settings → Linked devices → Link a device. After the first sync, launch whatsapp-gui --toggle — it finds the local wacli store automatically and stays paired permanently.

Inline Media

Watch Social Videos & Reels Directly in the Window

When friends send Instagram Reels or media links, you shouldn't have to break your focus and launch a heavyweight desktop browser. whatsapp-gui plays social videos right inside the chat window.

🎬

Embedded In-Window Player

A specialized, hardware-accelerated Qt WebEngine overlay renders Instagram Reels and social video embeds directly inside the blade. Audio and video play instantly with full autoplay support.

⚡

Zero Browser Context Switching

Keep chatting without opening browser windows, managing unwanted tabs, or cluttering your daily browsing session with one-off video links.

⌨️

Instant Esc Dismissal

Done watching? Hit Esc or click Close to immediately sheathe the player overlay and return seamlessly to your conversation. An Open externally button remains available whenever you need the full web page.

Hyprland Integration

Right-Edge Blade Window

whatsapp-gui is dimensioned as a 560px right-edge blade. Hyprland handles window movement, floating, and slide animations via your desktop configuration.

Add these rules to ~/.config/hypr/looknfeel.lua:

~/.config/hypr/looknfeel.lua 
o.window("^(whatsapp-gui)$", { name = "blade-whatsapp", float = true })
o.window("^(whatsapp-gui)$", { size = { 560, "monitor_h - 26" } })
o.window("^(whatsapp-gui)$", { move = { "monitor_w - 560", 26 } })
o.window("^(whatsapp-gui)$", { animation = "slide right" })
o.window("^(whatsapp-gui)$", { rounding = 0 })

Bind your preferred toggle hotkey in your Hyprland configuration (e.g. Super + M):

~/.config/hypr/hyprland.conf 
bind = $mainMod, M, exec, whatsapp-gui --toggle
⚡

Memory Resident & Instant Wake

Closing or toggling the window simply hides the surface while keeping the process warm in memory. Triggering the toggle hotkey brings it back into view in under 10ms.

🗡️

Hierarchical Esc Behavior

Pressing Esc when watching a video closes the video overlay. Pressing Esc in a chat returns to the conversation list. Pressing Esc from the chat list sheathes the blade.

Capabilities

Native WhatsApp Features

A comprehensive messaging experience designed for speed, privacy, and full keyboard control.

🎙️

Voice Notes & Audio Recording

Record voice messages with the built-in microphone tool. Audio playback includes position indicators, simulated waveform bars, and clear playback timing.

🖼️

Albums & Image Galleries

Multi-image photo bursts collapse into compact grid tiles so they don't consume your entire thread height. Clicking opens the high-resolution media viewer.

💬

Replies & Reactions

Quote-reply to any incoming or outgoing message. Add, toggle, and view emoji reaction counters with instant local optimism.

💾

Offline SQLite Mirror

All messages, contacts, and metadata are mirrored into a local SQLite database by wacli. Search and browse your message history instantaneously, even while offline.

✓

Unread Counter & Mark Read

Mute-aware unread badges keep your chat list organized. Click the mark-all-read checkmark (✓) to clear badges across all active chats at once.

🔗

CLI Chat Deep-Linking

Open any chat directly from your application launcher, scripts, or rofi with whatsapp-gui --chat <jid>.
